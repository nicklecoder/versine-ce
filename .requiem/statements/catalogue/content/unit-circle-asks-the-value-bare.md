On the unit circle x is the cosine and y the sine, so an exact value is asked for bare, 'Find the exact value of sin 30°', never as 'x = sin 30°', which would contradict the lesson that x means cos θ. The same wording is used in identities. The point-coordinate questions keep their letter, since there the letter is the coordinate asked for. The roots input's preview still writes x = when the student types no letter; that is the shared input's default and is not changed per level.
