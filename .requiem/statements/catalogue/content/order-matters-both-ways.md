In Does Order Matter? every context (medals, committees, seats and so on) must appear with both answers: an ordered version and an unordered version of the same setting. A review found the context alone gave the key away (every committee unordered, every race ordered), so learners could match words instead of asking whether swapping two picks makes a new outcome. The permutation and combination levels share the same ten settings, and the checker confirms each code is in the ordered or unordered set its rule expects.
