An answer kept in terms of π is typed as the number of π, a decimal, into a blank set before a π the prompt already writes (C = ? π); an answer with π taken as 3.14 is a plain decimal, and each question says which it wants. The expression parser is not taught the π character for this: the decimal box is what the rest of the skill uses, and typing 10pi as an expression would make the student write the π the question already shows.
