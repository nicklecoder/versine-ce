Every box-plot value a question depends on (minimum, quartiles, median, maximum) must sit on a labelled tick of the axis, and two box plots compared by a measure must differ in it by at least one tick step. A review found values between ticks, where reading the plot could not tell the answer. On reveal, the plot also prints the values it used. Labelling every value instead was rejected: it turns reading a plot into reading numbers.
