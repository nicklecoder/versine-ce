Inequalities' solving levels (Undo by Adding, Undo by Multiplying, The Flip, Unknowns Both Sides, and All Together, which deals only from them) ask for the solution written as an inequality, judged as a set, instead of the smallest or largest integer that works. Asking 'the smallest' told the student the answer had the form x > something, so in The Flip the question announced that the sign had turned before the student turned it; and no level ever had them write the solution. The integer reading was chosen when no answer box could take a range, which the solutions type now does. Which Numbers Work keeps it, since there the first integer and the strict-or-not difference are the lesson, and it says 'integer', not 'whole number', which in American usage starts at 0.
