The multiplication-principle level draws from several kinds of choice (menus, codes, plates, pegs, quiz answers and coin flips) rather than menus alone, and the problem text names the kind so the checker reads each one. One context made the level feel like a single problem repeated, and a learner who only saw menus never met repeated choices from the same set.
