inverses' rules go past lines toward F-BF.4a: besides ax + b, (x + b)/a and a(x + b), they include a fractional slope ((2/3)x + 4, undone by multiplying by 3/2), a − bx, x³ + b and ∛(x − b), which undo each other, and (ax + b)/(cx + d), undone by solving for x across the fraction bar (its inverse (b − dx)/(cx − a)). The same families give Undo a Function its values. A cube-root answer is typed root(3, …), which the prompt says. Undo a Function and Solve for x ↔ y depend on roots' Cubes and Cube Roots for the cubes, and the table of values is no longer always x = −2 to 3.
