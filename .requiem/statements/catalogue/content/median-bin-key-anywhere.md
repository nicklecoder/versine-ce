In "which interval contains the median", the key's position among the options is drawn first and kept on a redraw, so each position is about equally likely. The options stay in axis order, so before this the median bin, which tends to sit in the middle, was almost always the middle option. The tallest bar is a decoy whenever it fits, because confusing the mode with the median is the common mistake.
