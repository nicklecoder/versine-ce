The reasoning skill asks whether a statement, its converse, inverse or contrapositive is true, or whether it makes a biconditional, only about whole numbers from 1 to 200, quadrilaterals and triangles, where the answer can be checked over every case. Everyday statements ("If it rains, then the game is canceled") appear only in questions about structure: naming the hypothesis, building a form, and which form must share the truth. Their truth depends on the world, so a true or false answer about one would be an opinion. The skill also opens with a Hypothesis & Conclusion level that the Phase 3 plan did not list, because "q if p" and "p only if q" have to be read correctly before any form can be built.
