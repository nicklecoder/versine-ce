In laws-sines-cosines, every Sines: Angle problem (two sides and an angle not between them, solving for an angle with the law of sines) states how many triangles fit. When there is one, because a ≥ b or the given angle is obtuse, the prompt says so. When there are two, it names the triangle meant, the one where B is acute or the one where B is obtuse. An inverse sine gives only the acute angle, so a question that left the ambiguous case open would have two right answers and mark one of them wrong. The separate How Many Triangles? level asks for the count itself. Its rows keep a clear of the height b sin A by at least 0.3, unless a equals the height exactly (A = 30°, a = b/2), so the count is never a rounding judgment.
