Every radical-eq prompt says the answer may be none: 'Solve … . Give every solution, or none if there is no solution.', as trig-equations words it. Between a tenth and a third of each level's rows have no solution, and a bare 'Solve:' told the student there was something to find, which made 'no solution' read as giving up rather than as an answer. The wording names a spelling the solutions box reads as the empty set ('none'); an earlier 'or say there is none' invited 'there is none', which the box refuses.
