Functions' Domain and Range asks for the whole domain or range written as a set (-3 <= x <= 5, judged by the solutions type, so [-3, 5] is right too), not one endpoint as a whole number, because the domain is the set of inputs and a level that only ever asked for its smallest x never had the student say what a domain is. The graphs are unbroken with filled ends, so both ends are kept and the range runs from the lowest point to the highest.
