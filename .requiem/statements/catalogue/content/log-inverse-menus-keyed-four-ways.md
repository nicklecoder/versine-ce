Log Functions' which-is-f⁻¹ choices draw four functions for every set of four options, one keying each option: log_b(x ∓ k) and log_b x ∓ k are the inverses of bˣ ± k and b^(x ∓ k); log_b(x/c), log_b(cx), (log_b x)/c and c log_b x of c·bˣ, bˣ/c, b^(cx) and b^(x/c); and the powers the same way round for the logs. At 85b18ac only c·bˣ and bˣ/c were drawn, so the key always had c inside the log: the two inside options tied as medoids, a student who knew only that the number goes inside picked between two, and scripts/measure-medoid.py measured 40 of 278 rows because the twin option sets read as a fixed menu. With all four functions drawn the option set is a genuine fixed menu -- the options alone say nothing, and each is the key about a quarter of the time -- so leaving those rows out of the medoid measure and judging them by the key moving (fixed-menu-key-moves) is right, not a gap in the measure. The two slips crossed are still the order of undoing and the direction of a step, so knowing either rule halves the options.
