radical-eq has a Square Twice level after Both Sides Radical, because squaring a root with a number beside it leaves a second root to isolate and square, which is a technique of its own and had been 2% of Both Sides Radical. It mixes √(x + a) = √(x + b) + c, the same as a difference, √(px + a) = √(x + b) + c (a quadratic in u = √(x + b)), and √x + √(x + a) = c, each built from the second root's value u so that a u below 0 is an extraneous answer: about a quarter of rows keep an answer the check throws out.
