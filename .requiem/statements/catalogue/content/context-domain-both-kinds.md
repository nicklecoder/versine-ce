In domain-range's Domain in Context, every story setting (apples, rice, juice, fabric, gasoline, rope) appears both as a measured quantity (pounds, liters: every real number from 0 to the limit) and as a counted one (bags, bottles: the whole numbers 0 to the limit). If a setting came only one way, the product named in the story would give the answer away without the student asking whether the input is counted or measured, which is the thing the level teaches. The wrong options include the range's top value, the maximum cost, offered as a domain limit, because confusing the cost with the quantity bought is the usual slip. Refines order-matters-both-ways, the same rule for Does Order Matter?.
