An answer typed after opening the Why? walkthrough on that problem is solved but is not a first try: it does not count as clean, does not extend the streak, and is logged as not correct first time. The walkthrough ends on the answer, so counting it let a student read every answer and score 100% first try, and gave the teacher console the same false accuracy.
