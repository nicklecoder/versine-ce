A prompt whose widest unbreakable piece -- a bracket, or a product set side by side -- runs long is set at a smaller size, measured from the question so a reveal never resizes it. Those pieces are kept on one line, because a bracket that breaks across lines no longer reads as one factor; the cost is that a long one cannot wrap, so the line has to shrink to fit the card instead.
