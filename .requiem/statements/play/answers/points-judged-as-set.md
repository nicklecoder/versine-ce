Where curves meet, and the one solution (x, y, z) of a system in three letters, the answer is typed as points in brackets and judged as a set of exact points: any order, a point said twice counted once, commas, semicolons, and or or between them, each coordinate a whole number, fraction or decimal compared exactly, and none (or no points, they do not meet, no solution) as the empty set, which equals an empty set of any size. A point keeps its order, so (3, 4) is not (4, 3). Judged as a set because the question asks for every meeting point and no order among them is the right one; one box rather than a box per point because how many points there are is part of what is asked. Some of the points but not all is wrong and told there are more, the way a set answer missing a part is; a point with the wrong number of coordinates, a pair where (x, y, z) is asked, is asked again rather than marked, since it answers a different question.
